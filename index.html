🤖 Android Capacitor Project Ready

How to Install & Build APK

You have 2 convenient ways to run this on your Android device:

Method 1: Instant Install on Android (PWA)

  1. Run the dev or preview server (`npm run dev -- --host`).
  2. Open the URL on your Android phone's Google Chrome.
  3. Tap the "Install TrackWise" or "Add to Home screen" prompt.
  4. It runs full-screen, offline, with its own app icon just like a native app!

Method 2: Standalone .APK Build (Capacitor)

The native Android platform has already been integrated in the android/ directory.

# 1. Sync latest changes
npm run cap:sync

# 2. Open Android Studio
npm run cap:open

# 3. Or build APK directly via Gradle:
cd android && gradlew.bat assembleDebug

The generated APK will be at: android/app/build/outputs/apk/debug/app-debug.apk
